# 视频风格案例与提示词

本机 0.3.4 Pro 新增原生「风格案例」页面。入口为 **处理素材 → 风格案例**，也可从 **创作室 → 模板 → 查看视频风格案例与提示词** 进入。

## 日常使用

1. 在列表选一种风格，或搜索「白板」「像素」「产品」等关键词；类型筛选可与搜索组合。
2. 在右侧播放原片参考片段；点击「查看画面证据」对照视频中的提示词卡。「查看来源」打开原作者页面。
3. 切换「工作适配版」或「画面整理版」，点「复制提示词」。前者为针对工作场景改写的可执行简报；后者来自视频可见卡片，经换行与识别纠错整理，不代表作者完整对话。
4. 在「换成我的主题」填写本次选题，点击「复制调用指令」，粘贴到 Codex 或其他视频制作会话。已选择工作台项目时，指令会带上项目名称和目录；未选择时可以直接用于当前制作目录。
5. 修改本地案例文件后点击「刷新案例」；搬动整个资料库后用「更换案例库」重新选择包含 `cases.json` 的目录。

复制调用指令不会自动启动生成、安装外部 Skill 或发布内容。参考片段与新生成成片分别标识；15 个工作适配案例当前是制作简报，并未额外渲染成 15 条新视频。

## 文件与实现

- 安装应用：`/Users/chenshuo/Applications/CS 工作台 Pro.app`
- 默认资料库：`~/Documents/ChatGPT/陈硕 video/资料库/Opus5.5十五种视频风格_20261018`
- 索引：`cases.json`；每个 `cases/编号/` 保存参考 MP4、画面与证据 JPG、Markdown 和两版提示词 TXT。
- 源文件：`src/VideoReferences.tsx`、`src/video-references.css`、`lib/video-references.cjs`；主进程和 preload 提供受控 IPC。
- 案例视频和图片通过现有 `cs-media` 本地媒体通道加载，正式应用不依赖 localhost 服务。
- 索引读取只允许库内文件，检查路径穿越、越界符号链接、媒体扩展名和重复编号。缺少视频仍可查看、复制提示词。来源仅允许无凭据的 HTTPS 链接。
- 案例媒体保留在用户资料库中，不装进应用包或 Git 仓库。原片及截图归原作者，适合个人参考；对外分发需另行确认使用权限。
