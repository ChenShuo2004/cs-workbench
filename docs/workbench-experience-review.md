# 工作台体验优化验收

范围：整个工作台的视觉层次、导航与查找、动态反馈、键盘操作和恢复状态。沿用 KAI、纯白默认主题和现有四套语义配色；不改变视频模板、媒体色彩或生成模型参数。

## 审查发现与修改目标

| 问题 | 影响 | 实现与验收目标 |
| --- | --- | --- |
| 小窗口的流程导航仅剩数字，缺少可读名称 | 难以找到创作室及其他目的地 | 可展开的完整导航；选中页可辨识，窄屏可关回内容 |
| 全局搜索先切到首页，打断当前编辑上下文 | 只是查找也会离开创作页面 | 原地打开统一搜索，页面、项目、任务、记忆和会话可直达；取消保持页面和输入 |
| 多个弹窗只有遮罩，没有焦点约束与恢复 | Tab 可进入背景，Escape 行为不一 | 复用原生模态层，键盘焦点留在弹窗内，关闭回到触发按钮 |
| 动效与密度散落，缺少用户偏好 | 不同页面节奏不一致 | 统一短时过渡，提供舒适/紧凑、跟随系统/轻柔/减少动态效果，重启保持 |
| 初始化失败仍显示无限加载，提示定时器可提前清除新提示 | 错误不能恢复，反馈丢失 | 明确失败、重试；提示计时与当前消息一致 |
| 卡片、导航、标题与边界缺少层次 | 首屏扫描与点击反馈弱 | 统一间距、层次、焦点、悬停；保持真实数据和页面用途 |

## 验收机制

1. 修改前检查真实组件、既有界面与数据边界，记录可复现缺陷。
2. 修改后构建、类型检查和适用单元测试。
3. 在隔离用户目录的 Electron 中操作：全局查找与返回、导航、弹窗焦点、主题/密度/动态偏好与重启、失败重试、桌面与窄屏溢出。
4. 回归个人工作区、创作室与画布 `@` 自动连线；使用测试数据与模拟生成服务，不消耗真实生成额度。
5. 打包后在真实安装包复验，保留旧安装包及用户数据。通过情况写入 evidence；未完成检查明确列出，不用源码推断替代 UI 验收。

## 0.7.0 的实现

- `WorkspaceSearch.tsx`：统一搜索页面、项目、任务、资料、记忆、会话和目录；查询留在当前编辑上下文，确认跳转后才保存并离开。支持方向键、回车、Esc、输入法组合输入及读取失败重试。
- `Dialog.tsx`：新建选题、剪辑项目、任务、记忆、数据备份、xAI 配置、导出队列与账号表单共用原生模态层；背景不可获得焦点，退出恢复焦点；失败原因显示在弹窗内部。
- `Appearance.tsx`、`experience.css`：语义化表面、标题、间距、边界、焦点和悬停；舒适/紧凑密度；跟随系统/轻柔/减少动态效果，偏好持久化。页面短淡入、弹窗短过渡，不对画布位置和尺寸做过渡。
- `main.tsx`：窄窗口完整导航抽屉、当前页标识、跳到主内容、启动失败重试、新建防重复提交、当前通知独立计时及可关闭提示。
- `Personal.tsx`：搜索结果直接打开具体记录；初始化异常可重试；聊天滚动尊重减少动态效果。
- `ui-error.ts`：保留实际错误原因，去掉 Electron 的传输层技术前缀。

## 0.7.1：保存、切换与退出的完整链路

审查沿“输入 → 保存 → 切页/切项目 → 重启 → 导出”追踪状态，而不只看页面是否能打开。

| 定位的问题 | 修改 | 验证 |
| --- | --- | --- |
| 保存请求结束时把随后输入也标成已保存 | 共用不可变快照保存队列，写入后只确认对应内容；继续写入排队的新版本 | 单元测试与真实 Electron 延迟写入，核对磁盘最终内容 |
| 内容计划加载时可被输入抢先，切换项目可能丢修改 | 加载结束后开放表单；切换前保存，失败留在原计划；导出包含当前修改 | 挂起读取/保存 IPC、切计划与查找导航 |
| 随手记失败没有就地重试，切页可丢恢复机会 | 明确未保存/等待/保存中状态，失败保留文本，恢复按钮与离开保护 | 故障注入、再次写入并读取实际本地记录 |
| 同一文章标签重开时读取了保存前的旧快照，慢项目读取覆盖新选择 | 使用最新文档快照，项目请求按最后一次选择生效 | 连续编辑、点击当前标签、反序完成项目读取 |
| 画布失败链阻断后续操作，窄屏不能看到重试 | 失败可重新保存当前画布；持久重试条；切页等待整个保存队列 | 连续失败、关闭错误提示、390px 重试、检查节点落盘 |
| `⌘S` 在内容计划页仍只保存文章 | 保存当前模块，完成后才提示 | 内容计划快捷键与真实文件读取 |
| 用户取消退出后后台服务已提前停止 | 仅在最终退出时关闭后台；未保存窗口提供继续编辑/放弃关闭 | 原生关闭事件、保留输入并继续创建任务 |
| 跳到主内容改变 URL hash，影响全屏来源匹配 | 仅移动焦点，保留主窗口 URL | 键盘触发与 URL/焦点检查 |

可复用模块：`shared/draft-save.mjs`。所有者提供当前脏快照、写入函数与确认函数；失败不会确认保存，并发 flush 合并为同一个请求，保存过程中新增输入继续顺序写入。

新增复现：

```sh
npm run build
npm test
node scripts/verify-draft-safety.cjs
node scripts/verify-responsive.cjs
```

故障注入脚本使用临时用户目录，只拦截测试进程的 IPC，不修改真实用户文件或服务。安装版的成功流程另行复验。

## 0.7.2：目录读取不再卡住整个窗口

实际启动采样显示主线程停在同步文件 `open()`；复制真实项目指针、个人记录与内容计划到隔离目录后可以复现配置，但开发版能读，安装版曾阻塞。未把无法确认的原因断言成用户钥匙串或目录损坏。

- `lib/workspace-reader.cjs` 将启动的项目与素材库读取放入后台线程；主线程继续响应。
- 10 秒没有结果显示明确错误与「重新打开工作台」，重试共享尚未结束的读取，不叠加挂起的扫描；不改写来源文件。
- 阻塞解除后恢复原工程；最终退出时关闭后台读取。
- `tests/workspace-reader.test.cjs` 与 `scripts/verify-startup-recovery.cjs` 使用 FIFO 制造真实系统文件打开阻塞，验证主线程仍可响应、超时、重试和恢复。
- 最终安装版 0.7.2 已通过这两项故障界面检查；真实用户目录启动已看到完整首页、已有连接目录与原记录。另使用不含密钥的真实数据副本验证安装版搜索与设置操作，验证后删除该临时副本。

单独的画布测试曾在写入模拟密钥时等待系统钥匙串，进程采样定位到了 `SecItemCopyMatching`；已移除该 UI 测试中不必要的模拟凭据写入。画布仍检验真实持久化数据、编号映射及断线 IPC 错误；供应商协议由集成/单元测试覆盖。未改变生产密钥保护或代替用户进行系统安全授权。Electron 官方说明同步密钥调用可能等待系统输入，参见 [safeStorage](https://www.electronjs.org/docs/latest/api/safe-storage)。
