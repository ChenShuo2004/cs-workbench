# 麦田内嵌与工作台精简 · 0.8.0

2026-11-17，本机版本。入口：工作台「分发与复盘 → 发布与复盘」，也可在「内容计划」点同名按钮。

## 使用方式

麦田原网页直接显示在 CS 工作台内。大屏、流量、日历、档案、系统操作继续使用同一套麦田服务和数据库。网页里的排期、作品状态和数据由麦田负责；工作台提供创作与项目文件。需要准备视频分发时，继续使用已安装的 `maitian-publish` skill 和 `~/maitian` 工具链。

顶部可刷新网页或重新选择麦田安装位置。默认读取 `~/maitian/mdldm-maitian/config.json`；自定义安装目录保存在工作台配置的 `maitianRoot`。麦田离线、配置缺失或认证失败时显示错误与重试入口。

工作台选题计划的日期仍是本地创作计划，不自动转换为平台定时。网页原系统页仍不提供视频上传表单；实际多平台上传按麦田已有发布流程执行。

## 精简范围

- 移除健康、亲人重逢的页面、导航、preload 接口和主进程运行入口。
- 移除旧账号卡片重复的「读取资料与作品数据」入口，数据统一查看麦田原网页。
- 保留多账号独立 Chrome 登录、内容计划、原项目、剪辑与 Agent；独立账号浏览器与麦田专用浏览器仍是不同会话。
- 原视频发布步骤条和七个平台手动状态表不再并列显示；文章交付包及公众号等其他渠道的手动记录保留在折叠区。
- 用户数据目录中的健康、亲人重逢、账号快照与登录资料保留，不做数据删除。历史维护/恢复模块和旧测试不代表功能仍在应用中开放。

## 接入边界

`src/Distribution.tsx` 使用 sandbox iframe 载入原网页；`index.html` 只放行本机 127.0.0.1 的网页框架。主进程读取访问口令，原网页地址和渲染层快照中不带口令；仅为当前工作台窗口发往已配置本机端口的请求加入认证。其他域名、端口和窗口不会获得该口令。

内嵌网页没有 Node 或工作台 preload 能力；IPC 来源检查同时要求主窗口和主框架。网页导航限制在已配置的本机源，外部作品链接在常规浏览器打开。

源码位置：`lib/maitian.cjs`、`src/Distribution.tsx`、`src/distribution.css`、`electron/main.cjs`、`electron/preload.cjs`。麦田仓库程序源文件保持原样。

## 复现与检查

```sh
npm test
npm run build
npm run verify:distribution
npm run package:mac
```

`tests/maitian.test.cjs` 检查访问口令隔离、同源和端口限制、配置变更、离线恢复和非法请求头；`scripts/verify-maitian.cjs` 只读检查本机原网页及 API，不上传、不发布。结果在 `out/maitian-qa/`。

0.8.0 已通过 86 项单元测试、构建和打包。安装版严格签名检查通过；安装记录、旧版应用和用户数据备份位置见 `docs/evidence/maitian-install-20261117.json`。产物目录位于文件同步空间时，Finder 属性可能使该目录内的严格签名检查失败；本机安装流程在 Applications 下清理属性并重新签名，再检查安装版。

安装版实际 UI 检查：内容计划仍显示原有的两个项目与已保存简报；健康导航已移除。点击「发布与复盘」后在同一窗口显示本机原麦田大屏及六个平台的已采集数据，随后切换日历并返回大屏成功，无需再次输入网页口令。截图实际检查了完整桌面窗口中的布局。窄屏和外部作品链接未在本轮手工验收。

正式视频上传、七个平台发布结果与 Instagram 登录仍需实际内容验收；本次检查没有发布内容。
