# 健康页本地刷新按钮修复

## 问题与修复

原按钮调用 `healthRead()`，但没有手动读取状态或成功反馈。同一份记录再次读回时界面完全不变，用户无法判断点击是否生效。

- 显示读取中状态并禁用重复点击。
- 完成后显示本地检查时间、是否有变化和最新记录日期；无变化明确提示。
- 聚焦、30 秒轮询与手动点击共享进行中的请求，防止响应顺序导致回退。
- 15 秒超时或读取失败保留旧卡片，显示原因及重试入口；超时后的迟到结果不更新卡片。
- 区分网页采集时间与本地检查时间。按钮只重读本机文件，不触发网页采集，也不修改数据文件或采集时间。
- 体重隐藏和无需补录保持原样。

## 复现 UI 验收

构建后启动 `node scripts/preview-health-refresh.cjs`，用浏览器打开输出的本地 URL，进入健康页。脚本输出的 `root` 是独立临时目录；修改该目录的 `control.json` 可模拟延迟（`delayMs`，最多 30000）与错误（`error`）。通过 `createHealth(root).save(...)` 增加明确标记的验收样例，再点击刷新验证卡片变化。严禁将样例写入真实用户数据目录。
