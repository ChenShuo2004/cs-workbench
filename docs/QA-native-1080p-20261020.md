# 0.5.2 原生 1080P 验收

## 改动与依据

直接查阅 2026-10-20 [秘塔实时页面与 API 弹窗](https://metaso.cn/minimax-h3)：H3 已开放原生 1080p，同一接口还支持 `seedance-2.0` 标准版。搜索缓存及此前引用的文档不代表当前接口，0.5.1 的转码判断已经纠正。

视频节点、AI 面板与批量生成共用 `shared/video-models.json`。新建视频节点默认 H3 / 原生 1080P；两个模型都发送 `resolution: "1080p"`，直接保存服务返回的 MP4。Seedance 不发送 `fast_mode`，使用首尾帧时请求自适应比例。模型切换时自动修正不兼容的分辨率。图像生成及图片→视频依赖保持现有流程。

仅历史 0.5.1 的 1080P 任务保留原先的 2K 请求及本地转换逻辑。新任务持久化 `nativeResolution: true`；重新打开历史任务不会重复提交付费请求。原生任务收到非 1080P 尺寸的视频时报告错误，不自动转换。
