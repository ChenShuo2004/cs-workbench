# 视频创作画布 · 0.6.2

入口：CS 工作台 Pro → 创作内容 → 创作室 → 创作画布。

**0.6.2 当前操作：** 在提示词里输入 `@` 直接选择画布素材，选中后自动插入引用并建立连线，无需先连线。也可以手动拖线。不再选择图片参考 / 视频参考 / 声音参考端口，也不用切换全能参考模式。首尾帧通过节点内「首尾帧设置」从已连接图片中选择。详见 [直接连线与 @ 引用](canvas-mentions.md)。下方版本条目保留各阶段记录，旧端口操作已由此替代。

1. 选择已有项目，或点击项目名称旁的加号新建项目。
2. 在底部输入框逐行写分镜，选择比例与每镜头时长，点击「添加分镜」。创建的是可渲染的本地场景模板，不是 AI 生图/视频结果。
3. 点击左侧素材图标，导入 PNG、JPG、WebP、MP4、MOV 等本地图片/视频/音频。素材复制到项目，原件保留。点击「添加到画布」添加镜头；音频可设为背景音乐。
4. 拖动卡片标题摆放，选择工具下拖空白处框选；空格 + 拖动、中键拖动或切换抓手平移，⌘ / Ctrl + 滚轮缩放。自动排列、适应全部内容在工具栏。便签仅供参考，不进入成片。
5. 点卡片设置，可编辑字幕、画面提示词、时长、绑定图片/视频、前移/后移、复制/移除镜头。**成片按编号排列，画布空间位置不改变成片顺序。** 内容和布局修改可使用顶部撤销/重做；平移、缩放与输入草稿不占用撤销步骤。
6. 点击「预览与精剪」连续播放，并调整剪辑、字幕、配音、背景音乐、720p / 1080p。点击「导出视频」生成 H.264 MP4，进度与结果在导出队列。

画布布局、镜头和便签自动写入项目 `video/studio.json`。导入文件在 `assets/media/`，导出结果在 `outputs/render-<id>/final.mp4`。保存未成功时顶栏会显示错误，切换项目会等待保存队列完成。

## 全屏与画布操作

- 顶部「全屏」或非输入状态按 **F** 进入/退出创作室全屏；**Esc** 退出。macOS 使用当前桌面的原生全屏，保留工程选择、保存状态、撤销、精剪和导出。素材预览打开时，Esc 先关闭预览。
- **V** 选择，**H** 抓手；**空格 + 拖动**临时平移。空白处拖动框选、Shift 点击卡片标题增减选择；多选后拖动标题成组移动，或顶部对齐、批量移除。移除可撤销。**⌘/Ctrl+A** 全选，Delete/Backspace 移除选中项。
- 卡片标题右侧眼睛按钮打开镜头大图预览。图片可缩放、拖动与复位；视频有原始素材播放控件，成片切点仍在精剪中查看。
- 底部「成片顺序」拖动镜头调整输出顺序，画布中的空间位置保持不变。
- 右下角导航图点击定位，**0** 适应内容。视野外卡片暂不加载，减少大量媒体的预览开销。
- 输入框草稿自动存入当前工程，切换到精剪或重启后仍可继续填写。

## 0.4.0：画布内 AI 生图

顶部「AI 生成」打开侧面板。输入画面描述、比例和镜头停留时长，点击「生成图片并加入画布」。也可以从已有镜头设置点击「用这个提示词生成」，或选择项目里的图片作为参考进行改图。参考图片会交给所选生图服务处理。

当前使用本机已安装的 `cs-codex-image` MCP 和已有 Codex/ChatGPT 登录，不要求图片 API Key。生成使用账户额度；连接检查不等于额度足够，实际结果以任务状态为准。

生成完成后自动复制到项目 `assets/media/`，创建新镜头，保留原镜头和生成期间的编辑。新镜头可预览、设置时长、精剪并导出 MP4。描述不自动烧录为字幕。任务提示词、参考图、原任务编号和状态保存在本机；草稿随工程保存。

「暂停查询」只暂停本地查询，服务端可能继续生成；「继续查询」使用原任务编号，不再次提交。提交超时且没有任务编号时不自动重试，避免重复消耗额度。应用重启会恢复已有编号的查询；完成后重复加载不会重复加入镜头。误撤销加入的镜头时，生成素材仍在素材库里，可以重新添加。

## 0.4.1：秘塔 MiniMax H3 视频生成

在同一个面板切换「AI 视频」，使用 MiniMax-H3，选择 2K / 768P、4–15 秒和比例，点击「生成视频并加入画布」。选用首帧时，图片上传到秘塔，视频比例跟随图片；首帧最短边至少 256 像素、宽高比 2:5–5:2、文件最大 30 MB。可以把刚生成的 AI 图片直接选为首帧，继续生成视频。

「配置 / 更换秘塔 API Key」使用密码输入框；保存后清空输入。密钥通过 Electron `safeStorage` 系统加密保存在应用数据目录 `studio-generation/metaso-key.enc`，权限为 0600，不进入工程、任务历史或源码。连接提示中的“已保存”表示本机能读取密钥，实际鉴权与额度以生成请求返回为准。

适配依据：[秘塔官方 ComfyUI API 客户端](https://github.com/meta-sota/ComfyUI-MiniMaxH3-API/blob/main/api_client.py)。使用 `/api/minimax/v2/video_generation` 提交、`/v2/query/video_generation/{task_id}` 查询，以及 `/v1/files/upload` 上传首帧。标准模式 `fast_mode: false`。完成后下载 MP4、验证视频流和时长，再自动加入当前项目。下载 CDN 不携带 API 密钥。

生成消耗秘塔账户额度。暂停查询、恢复原任务、保存工程和回填的规则与生图一致。网络异常或提交结果不明确不会自动重新扣费生成；已拿到任务编号时可继续查询原任务。

## 0.5.0：可连线的生成节点

**图片 → 视频：** 点击「生图节点」写提示词，再建「视频节点」。把图片节点右侧圆点拖到视频节点的「首帧」，填写动作、选择秒数，点击视频节点「生成」。上游图片尚未生成时会一起列入任务预览，确认后先出图，再用该图片生成视频；已经生成的图片直接复用。也支持先点输出、再点输入，或键盘 Enter / 空格连接。

- **首尾帧：** 两张图片分别连接首帧、尾帧；也可只连一端。比例跟随帧图。图片可以来自已有镜头、素材参考节点、其他生图节点。
- **全能参考：** 视频节点切换为「全能参考」，分别接图片、视频、声音。最多 9 图、3 视频、3 音频；声音必须搭配至少一张图片或一段视频。参考标签按同类顺序显示 Image 1、Video 1、Audio 1，可直接写进提示词。切换模式移除不兼容的输入线，可撤销；素材保留。
- **素材入口：** 从画布素材库导入，点击「作为参考节点」后连线。视频、音频每段 2–15 秒，视频合计及音频合计分别不超过 15 秒。视频限 MP4/MOV、H.264/H.265、24–60 fps、50 MB；视频音轨为 AAC/MP3。音频限 WAV/MP3、15 MB。图像/视频宽高 256–5760 像素、宽高比 2:5–5:2。提交前校验。
- **逐镜秒数：** H3 视频支持每个整数 4、5、6……15 秒；分辨率 768P / 2K。图片的「镜头停留」支持 1–15 秒，不是生图耗时。
- **批量分镜：** 「分镜批量建节点」一行一镜，例如 `[5秒] 清晨树叶特写`、`[8秒] 拉远展示树林`。一次创建最多 50 镜，建节点不提交生成。每镜可单独改秒数、分辨率、模式和连线。
- **批量执行：** 多选生成节点后点「批量生成」；无选中生成节点时，选择尚无结果且未运行的节点。预览包含未完成上游、图片数量、视频数量和总秒数。最多同时推进 2 个任务；上游失败或取消，下游不提交。重复点击不会重复排队同一个节点。
- **结果与恢复：** 输出自动回到节点和镜头区；同批次按分镜顺序排列，不受完成先后影响。连接到下游的中间生成图片默认不计入成片，可在镜头设置重新启用。生成期间修改参数用于下次；已提交任务使用排队时的快照。重启恢复原编号查询，不重复创建付费任务。
- **整理画布：** 连续新建错开位置；自动排列按窗口宽高安排列数。标题拖动、多选移动、对齐、复制、移除、撤销、全屏均可用于生成节点；断线点参考标签的 ×。

协议依据：[MiniMax H3 官方接口](https://platform.minimax.cn/docs/api-reference/video-generation-v2-create)及[秘塔官方节点实现](https://github.com/meta-sota/ComfyUI-MiniMaxH3-API/blob/main/nodes.py)。这是现有两种生成服务的有向节点流程；不包含任意代码节点、音频生成或独立多轨视频合成节点。

## 0.5.2：原生 1080P 与 Seedance 2.0

视频节点新增「视频模型」选择，AI 面板和批量分镜共用同一模型配置。新视频节点默认 MiniMax H3 / 原生 1080P。可选择：

| 模型 | 本版接入的原生分辨率 | 时长 |
| --- | --- | --- |
| MiniMax H3 | 768P、1080P、2K | 每个整数 4–15 秒 |
| Seedance 2.0 标准版 | 720P、1080P | 每个整数 4–15 秒 |

选择 **1080P · 原生生成** 后，直接向秘塔发送 `resolution: "1080p"`，下载返回的原始 MP4，不经过本地转码。回填前验证原片短边为 1080；服务返回尺寸不符合时显示错误、保留原任务编号，不擅自转换。标准横屏为 1920×1080，竖屏为 1080×1920；首尾帧决定实际画面比例。

Seedance 使用同一加密密钥和 `/v2/video_generation` 接口，模型字段为 `seedance-2.0`，不发送 H3 的 `fast_mode`；首尾帧使用 `ratio: "adaptive"`。支持现有首尾帧、全能参考、逐镜秒数、队列和自动回填。切换模型会保留兼容的分辨率，否则切换为该模型默认 1080P。任务入队后保存模型和参数快照。

依据：2026-10-20 直接读取[秘塔实时生成页面及 API 说明](https://metaso.cn/minimax-h3)。页面已开放 H3 原生 1080p 和 Seedance 2.0；之前依据的缓存文档滞后。0.5.1 的“1080P（2K 转码）”入口已替换，仅历史任务仍按当时的 2K 请求继续本地转换，避免重新生成或改变原任务语义。历史成品不会冒充原生 1080P。

本版只开放上述已适配档位；页面还展示的 H3 16–30 秒、480p、Seedance 4K / Mini 不在本次接入范围。导出整条成片的分辨率仍由「精剪 → 导出分辨率」控制，与生成原片规格独立。

## 0.6.0：直接操作画布节点

- **双击空白处、右键空白处、左侧 + 或 Tab**：打开可搜索的节点菜单，在点击位置创建文本、生图、视频节点，或导入图片、视频、音频。
- **从节点输出圆点拖到空白处**：直接选择兼容的下游节点，创建与连线一次完成。图片可接视频首帧，文本接提示词，视频 / 声音接全能参考。
- **文本节点**：直接编辑内容，连接到生成节点的「文本提示词」输入。同一文本可连接多个分镜；生成时按连线顺序与节点自己的提示词组合，入队后固定快照。
- **右键节点 / 连线 / 分组**：复制、创建下游、预览、生成、移除、解组。点击连线后 Delete 删除，撤销可恢复。双击生成节点名称可改名，提示词可「放大编辑」。
- **⌘/Ctrl+C、V、D**：复制、粘贴、原位附近复制选中节点。内部连线一起复制；已生成的素材节点可复用，生成节点副本不会继承旧结果。跨工程节点粘贴不支持，外部图片可直接粘贴或从桌面拖入。
- **⌘/Ctrl+G / Shift+⌘/Ctrl+G**：分组 / 解组；分组可重命名、整体拖动。选择栏支持六种对齐、横纵分布、展开间距、批量连接兼容输入端口。
- **⌘/Ctrl+F** 搜索节点；**⌘/Ctrl+1** 100% 缩放，**⌘/Ctrl+2** 适应全部，**⌘/Ctrl+3** 聚焦选中，**⌘/Ctrl+ +/-** 缩放。输入框编辑时保留文字快捷键。

节点菜单只创建与编辑流程，点击「生成」或「批量生成」后才进入任务预览并提交。生成服务继续使用 Codex 生图、秘塔 H3 / Seedance 原生 1080P，以及首尾帧、全能参考、4–15 秒和批量依赖队列。

对照范围、参考实现和验收记录见 [画布交互对齐](QA-canvas-parity-20261020.md)。
