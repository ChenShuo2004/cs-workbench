# CS 工作台 Pro · 使用指南

版本 0.7.0，2026-10-20。本机可运行内测版，面向个人内容生产和工作管理。

## 打开

安装位置：`~/Applications/CS 工作台 Pro.app`。双击打开即可。原来的 `CS 工作台.app` 保留；Pro 使用独立的数据目录，首次启动只读取旧版的项目与素材库目录配置，不复制网页登录凭据。

本机已配置 FFmpeg / FFprobe 和 Whisper base；安装包未内置 FFmpeg 或模型文件，换电脑需另行安装。Codex / Claude 也通过本机 CLI 连接。

主入口是「我的工作台」。上半部分看今日进度、进入创作室和 Agent；下半部分添加任务、写随手记、查看连接的目录和操作记录。

## 从收集到交接的分类

侧栏按做事顺序展开，当前页面高亮。默认纯白，另有深林、海蓝和暮紫配色。在窄窗口点左上角菜单查看完整导航；进入页面后自动收起。

| 分类 | 入口 | 用途 |
| --- | --- | --- |
| 我的安排 | 我的工作台、内容总览、每日任务、健康 | 今日待办、随手记、内容计划、身体记录 |
| 01 发现信息 | 资料收集 | 保存来源链接和摘要、关联选题、标记已处理 |
| 02 处理素材 | 文件空间、素材库、风格案例 | 连接本地文件、挑选音频和字体、查看创作参考 |
| 03 决定选题 | 项目 | 管理目标、受众和每个项目的状态 |
| 04 创作内容 | 文章、视频、创作室 | 写文章、整理口播脚本和分镜、实际剪辑 |
| 05 分发交接 | 发布、平台账号 | 整理发布包、打开独立账号窗口、记录实际状态 |
| 常驻工具 | Agent 助手、个人记忆、设置 | 模型连接、长期偏好、本机配置 |

“当前创作项目”贯穿文章、脚本、剪辑和交接；在剪辑器切换工程也同步到全局。资料与记忆分开保存，旧记忆保持原样。收集资料不会自动抓取网页；填写摘要和来源后可继续编辑或归档。关联项目是引用，不会搬动源文件。

顶部「搜索或跳转」或 **⌘K / Ctrl K** 在当前页面上打开统一搜索，查找页面、项目、任务、资料、记忆、会话与连接目录。上下箭头选择、回车打开；Esc 返回当前页面，保留输入。打开其他页面前按现有规则保存文稿。目录搜索不递归读取硬盘内容。

## 外观与键盘

「设置 → 外观与阅读」提供四套配色、舒适/紧凑密度，以及跟随系统/轻柔/减少动态效果。偏好自动保存在本机，重启后继续使用。减少动态效果关闭界面过渡，不改变视频和媒体播放。

新建项目、任务、记忆、数据备份与账号弹窗支持 Tab / Shift Tab 在弹窗内切换，Esc 关闭并恢复焦点；提交失败会在弹窗中显示错误，保留表单内容。

创作室完整操作见 [视频创作画布](video-canvas.md) 与 [直接连线和 @ 引用](canvas-mentions.md)。输入 `@` 可直接选择画布素材，选中后自动连线。

## 每日任务与记录

1. 首页输入任务，回车保存。点击方框完成，点击任务文字修改。
2. 「每日任务」可以改日期、优先级、进行中状态、说明及关联项目。
3. 选择「每日例行」后，在目标日期点击「生成例行任务」。同一天重复点击不会重复创建，历史完成记录保留。
4. 首页随手记自动保存。任务更新、记忆修改、目录连接会记录在操作足迹中。
5. 归档只改变工作区记录；在「已归档」中可恢复任务，原始项目文件不会删除。

## 个人记忆

「个人记忆」支持创建、编辑、标签、置顶、归档与恢复。这里是工作台自己的记忆库，不等于自动读取所有 ChatGPT/Claude 云端聊天。只有你在 Agent 输入框的「带上记忆」中勾选的条目才会随该条消息发给模型。

建议分别保存创作偏好、项目背景、常用判断标准；避免把密码写入记忆。

## 文件空间

点击「连接文件夹」选择本机目录。不会移动或复制整目录。支持层级浏览和小于 250 KB 的常见文本/代码/字幕预览；其他文件可在 Finder 打开。隐藏文件、系统目录和越界符号链接不进入预览。

在文件预览上点击「带到 Agent 会话」，文件成为下一次消息的显式附件。断开连接不会删除原文件。不会自动扫描整个硬盘或上传目录。

## Agent 与模型

- **Codex / GPT**：复用本机 Codex CLI 的 ChatGPT 登录。已在此机通过真实回复验证。空模型名采用 CLI 默认值；下拉候选来自本机模型缓存，也可输入账户支持的模型 ID。
- **Claude Code**：已安装；当前未登录。在终端运行 `claude` 完成账号登录，再在 Agent 页面点击刷新。Claude 桌面版登录不等同于 Claude Code 登录。
- **Grok**：点击「Grok 网页」打开独立的官方登录窗口。网页与 API 是不同接入方式。想在工作台聊天，点击「配置 xAI」，填写 xAI Console 的 API Key，先验证模型列表再加密保存。API 密钥不写入备份、文档或日志。

工作台中的 Agent 目前是**只读分析会话**：整理文案、分析引用的文件、讨论任务。不会直接修改项目、执行发布或自动控制桌面。Codex 使用 read-only sandbox；Claude 关闭会话工具；Grok 只发送文本请求。消息会包含有限历史，以及你选定的记忆和文件。使用对应账户的额度。

会话可停止，历史和回复保存在本机。错误会显示在会话里；未登录和缺少 Key 不显示为已连接。

## 口播剪辑

1. 进入「创作室」，新建或选择项目。
2. 导入视频/音频。素材复制进项目，保留原文件。
3. 在「文稿」点击「转写」。本机 Whisper base 模型生成真实时间码，按词边界和标点拆句，并转成简体中文。专有名词和切点仍需人工校对。
4. 已有字幕也可导入 SRT；导入会替换当前轨道，可以撤销。
5. 取消片段勾选可删掉对应时间段。支持调起止时间、复制、删除、移动、播放头分割、撤销和重做。
6. 「静音检测」先计算候选停顿，再点击应用；原音视频不会改写。默认阈值 −35 dB、最短 0.45 秒，切点各保留 0.1 秒余量。
7. 选横屏/竖屏/方形/4:3、720p/1080p，再「导出视频」。可选完整显示留边或居中裁满；居中裁满不做人脸追踪。
8. 导出队列显示真实进度，可取消。完成后点击打开成片。

转写及 SRT 导入保留没有字幕的间隙；只有主动关闭片段或应用停顿剪除，才会缩短视频。

右侧制作设置支持：

- 字幕：清晰、醒目、底板三种样式；字体、颜色、字号、安全位置；单独开关及导出 SRT。
- 声音：素材原声、逐片段替换配音及起点、静音、整体声音音量；导出可统一到 −16 LUFS。
- 背景音乐：选择导入的声音，设置音量、起点、循环、淡入淡出和人声避让。导出使用真实侧链压缩；内置预览按固定比例估计避让，听感以导出为准。
- 节奏：从音乐前 90 秒估计 BPM，支持手动覆盖节拍和偏移。选中片段可向最近拍点微调结尾，最多 0.18 秒；复杂音乐或半拍误判需人工校正。

“打开剪辑助理”可用已登录的 Codex 或 Claude 对字幕时间线给建议。先显示改动理由和前后区间，再由你应用；可以撤销。发送的是文稿和时间码，不上传原始音视频。它能判断文本冗余，不能仅凭这些资料分析真实表情、语气或所有音乐重拍。过期工程、未知片段、越界切点和过度删减会被拒绝，显示错误供重试。

## 场景动画

切到像素模式或模板，从雾松森林、暮紫湖畔、琥珀书房选择环境。参考 P01 / P06 / P04 的色彩、光源与层次，画面由原创 SVG 生成，未使用参考原图像素。

每行文案生成一个场景，可逐段改文字和时长；支持像素环境与平面插画两种绘制模式。可导入音频并给场景指定配音源与起止时间，预览可播放对应声音。未绑定音频的场景导出静音轨，**不会伪装成已有 AI 配音**。通用小人不是 KAI 固定角色母版。

这是可编辑的参数化场景模板，不是自动生成任意复杂动画。代码视频、HyperFrames 等已有工程继续通过项目目录与交接文档使用。

## 文件在哪里

- Pro 设置、任务、日志、记忆、会话：`~/Library/Application Support/CS 工作台 Pro/`。
- 个人数据：`personal/workspace.json`，最近写入前备份为 `workspace.json.previous`。
- 项目：沿用配置的工作区，每个项目一个目录。
- 剪辑工程：`video/studio.json`。
- 导入媒体：`assets/media/`。
- 转写证据：`video/transcription-*.json`。
- 每次导出：`outputs/render-<ID>/final.mp4`、`captions.srt`、`timeline.json`、`verification.json`，场景动画还包含 `art-direction.json`。
- 最新成功成片：`outputs/final.mp4`。失败导出不会替换上一版成功成片。
- 本地 ASR：`~/.local/share/cs-workbench/asr` 和 `models`。

「备份工作区」导出任务、记忆、记录、会话和目录引用；不包含源媒体、完整项目或密钥。完整迁移还需复制项目目录。从首页的「数据与备份」选择恢复文件；应用会先检查格式和记录数量，再显示确认。恢复前的完整个人数据自动保存在 `personal/backups/before-restore-*.json`，有正在运行的 Agent 时暂停恢复。恢复会替换个人记录，项目媒体仍在原位置。

## 常见问题

- 无法转写：检查 FFmpeg 与本地 ASR；可运行 `scripts/setup-asr.sh` 重建环境。首次下载模型需要网络，之后音频处理在本机。
- 无法预览某些编码：先转成 H.264/AAC MP4。后端可探测的格式不等于 Chromium 都能预览。
- 导出失败：错误会保留在队列；修正工程后重试，队列中的重试按钮使用当前已保存工程。
- 强制退出：已完成文件保留；未完成队列标记为中断，需要手动重试，不自动宣称渲染完成。
- Grok API/Claude 未连通：需对应账号登录或 Key，不能复用不兼容产品的网页凭据。

## 多平台登录

「平台账号」→「添加平台账号」→选择小红书、视频号、公众号或抖音→填写备注→保存→「打开 Chrome / 登录」。每个账号使用独立 Chrome 目录保存会话，也可以添加同平台的多个账号。微信平台需要使用有该账号权限的微信扫码；添加备注并不等于登录成功。具体操作见 [多平台账号说明](platform-accounts.md)。


## 健康与内容总览（0.3.1）

首页新增健康概览；侧栏「健康」可看带日期和来源的记录、补录身体指标、查看已有日期的趋势、导出独立 JSON。0.3.2 已配置每 15 分钟 的 Codex 网页同步，需要 Mac、Codex、Chrome 与登录状态可用；不属于官方实时接口。页面展示最近成功时间、上游日期和错误，历史体重不当作今天的体重，缺失睡眠、心率保留空白。详见 `HEALTH-SYNC.md`。

侧栏「内容总览」直接使用现有项目：补充受众、唯一观点、开头钩子、事实证据、结尾行动和下一步，记录平台与计划日期，发布后留存链接、统计时间、效果和经验。切换页面前会尝试保存修改，失败时留在原页。完整度不是质量评分；计划不是平台发布。

健康和内容计划分别保存在用户数据目录 `health/records.json` 与 `content-ops/plans.json`。两页有独立导出入口，原「个人数据备份」不包含这两个新增目录。研究依据与运行方式见 `WORKBENCH-OPERATING-MODEL.md`。
