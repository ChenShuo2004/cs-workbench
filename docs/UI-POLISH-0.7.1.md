# 0.7.1 界面可读性与导航优化

日期：2026-10-20。基线：`c130a8d`（0.7.0）。分支：`ui-polish-0.7.1`。

范围只涉及工作台界面与交互，不改变视频模板、媒体预览、导出画面颜色、生成模型参数和数据格式。沿用 KAI、纯白默认主题和四套语义配色。

## 改前发现（实际运行 0.7.0 采集）

| 问题 | 证据 | 影响 |
| --- | --- | --- |
| 小字过多 | 首页可见文字中 8px 有 8 处、9px 8 处、10px 18 处；全部样式表有 7–9px 声明 106 处、10px 111 处 | 卡片说明、按钮次要文字、标签在 Mac 上难以阅读 |
| 侧栏图标重复 | 我的工作台/内容总览同图标；文章/个人记忆同图标；视频/创作室/风格案例同图标；亲人重逢/平台账号同图标 | 扫一眼无法区分目的地 |
| 单页分组需多点一次 | 「发现信息」只有资料收集，「决定选题」只有项目，仍需先展开再点击 | 常用的项目列表被藏起来 |
| 侧栏在 900px 高度溢出 | 展开「创作内容」后侧栏内容 915px > 900px，「当前项目」被挤出可视区域 | 13 英寸笔记本上看不到当前项目 |
| 品牌副标题折行 | `PLAN · CREATE · ORGANIZE` 在侧栏里折成两行 | 顶部品牌区不整齐 |
| 重复的搜索入口 | 顶栏已有「搜索或跳转 ⌘K」，工作台/任务/资料/文件/记忆/Agent 页头又各有一个「搜索 ⌘K」 | 页头噪音，主次不清 |
| 首页孤立的通栏条 | 「内容总览 · 选题、排期与复盘」是一条与上下卡片不一致的窄通栏 | 视觉层次断裂 |
| 复合输入框焦点 | 快速添加任务获得焦点时，圆角输入框内部出现直角黑框 | 看起来像错位 |
| 图标按钮缺少名称 | 首页「今天」卡片右下角箭头按钮没有可访问名称 | 读屏无法识别 |
| 头像资源过大 | `kai-avatar.png` 1254×1254、1.9 MB，界面最大只显示 180px | 启动与首页多加载约 1.9 MB |

## 修改

- 字号：页面样式 7→10、8/9→11、10→12px；画布与生成节点（密集布局）7/8→10、9→10.5、10→11px。字幕预览（`cqw` 单位）、导出与模板相关选择器不改。
- 侧栏：为 17 个目的地分配不同图标；单页分组直接跳转并在右侧显示目的地名称（项目分组带数量）；高度 ≤ 940px 的窗口收紧行高与分组间距；副标题改为「计划 · 创作 · 整理」并保持单行。
- 首页：健康卡与内容总览卡并排为两张同级卡片，窄窗口自动叠放；删除页头重复的「搜索 ⌘K」，保留「数据与备份」。
- 交互细节：快速添加任务改为整个输入框显示焦点；「今天」卡片箭头补充「查看全部任务」名称。
- 资源：界面头像改用 384px WebP（约 21 KB），原始 PNG 保留给图标与封面生成脚本。
- 验收脚本：`verify-appearance.cjs` 中「展开决定选题」改为直接点击「项目」，与新导航一致。

修改文件：`src/main.tsx`、`src/Personal.tsx`、`src/Brand.tsx`、`src/experience.css` 及各页面样式表的字号声明、`assets/branding/kai-avatar-384.webp`、`scripts/verify-appearance.cjs`。

## 验证（Linux + Xvfb，Electron 44，隔离测试数据）

- `npm run build`：通过。`npx tsc -b`：通过。Prettier、`git diff --check`：通过。
- `npm test`：75/76 通过；失败项为导出 ZIP 调用 macOS `/usr/bin/ditto`，在 Linux 沙箱不存在，与本次改动无关。
- `verify-experience`：10/10 项通过（原地搜索、焦点约束、四套配色、密度与动效、390px 导航、13 个页面无溢出、失败重试、重启保持）。
- `verify-generation-nodes`：6/6 通过。
- `verify-appearance`（2 项通过后停在「收尾检查」）、`verify-personal`（3 项通过后停在 Agent 发送）、`verify-canvas-parity`（7 项通过后停在合成文件拖放）：三者在未修改的 0.7.0 上于同一步骤以同样方式失败，原因是沙箱缺少 macOS 导出工具、本机 Agent CLI 与原生拖放，不是本次回归。
- 实测侧栏：1440×900 展开「创作内容」后高度 900/900，不再溢出；1280×800 仍需滚动约 74px。

未验证：macOS 真机与安装包外观、Retina 渲染效果、真实 Agent 与平台登录。Xvfb 下截图偶有一帧滞后，已用 DOM 状态确认导航高亮正确。

## 后续建议

- 主包约 509 kB：可按页面懒加载创作室画布与生成模块，缩短启动时间。
- 英文小标题（如 PERSONAL OPERATING SPACE）已放大到 11px；如希望界面语言统一，可改为中文。
- 1280×800 下可考虑把「当前项目」与「设置」固定在侧栏底部，导航区单独滚动。
