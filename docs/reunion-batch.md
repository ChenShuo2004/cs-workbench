# 评论截图批量制作亲人重逢上传包

入口：创作内容 → 亲人重逢。拖入或多选评论截图即可开始，每批最多50张，待处理队列最多100条。首次在固定参考中确认男主、老屋、旧电视与输出目录，以后每条仅需输入截图。

本机默认输出：`~/Documents/CS工作台项目/亲人重逢批量/日期-任务编号/`。

## 自动执行范围

1. 通过已登录的本机 Codex 读取截图，识别评论、亲属关系、明确事实与内嵌照片边界。
2. 提取原照片，保留完整截图；原图较小时等比放大便于上传，不声称恢复了原始细节。
3. 调用工作台既有 `cs-codex-image` 桥接，以原照片与头部区域为参考制作自然大头照。
4. 生成四句17秒创作对白、场景动作和一个电视转场。开场直接进入情绪，结尾保留约两秒停留。
5. 整理五张实际图片和一段全能参考完整视频提示词，检查图片解码、文件摘要与对白长度。

上传包包含男主、大头照、原照片、老屋、旧电视、完整提示词、上传说明、来源与检查记录。用户在全能参考工具生成视频；此入口不提交视频服务、发布内容或联系评论者。

## 状态与恢复

- 逐条执行；重复截图与相同固定参考不会再次排队。
- 没有目标照片、亲属关系不明、多位候选人物或定位越界：提示需要核对，不擅自补造或调用生图。
- 单条失败不会阻塞后面的队列；可重试单条或换清晰截图。
- 任务及参考副本保存在用户数据目录。重启后已知大头照任务沿原编号查询，避免再次提交。
- 提交结果不明确时不会自动重试，可关联服务端原任务编号后继续查询。
- 大头照含AI补全细节，对白是创作稿；文件通过检查不等于人物相似度或视频效果通过。

截图识别需要已登录的 Codex CLI；大头照使用已安装的本机图片桥接与现有账户额度。固定素材缺失时可在页面更换，路径不写死进应用资源。

## 实现

`lib/reunion-analyzer.cjs`：只读 Codex 图像分析与结构化输出。

`lib/reunion.cjs`：输入验证、裁切、17秒提示词、任务持久化、原任务恢复、上传包校验。

`src/Reunion.tsx` 与 `src/reunion.css`：批量入口、状态、预览、固定参考设置与失败恢复。通过经过主窗口校验的 IPC 访问本地文件，预览沿用 `cs-media`。
