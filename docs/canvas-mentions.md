# 直接连线与 @ 引用 · 0.6.2

入口：创作室 → 创作画布。

1. 直接在提示词里输入 `@`，列表显示当前画布里的图片、视频、声音、文本和可用生成节点，不要求提前连线。可输入节点名或文件名筛选。
2. 选中素材后自动插入引用并建立连线；文字和连线作为一次编辑保存，可一起撤销 / 重做。重复选择复用已有连线。普通编辑框与放大编辑一致支持方向键 / Enter 选择、Esc 关闭。
3. 例如：`让 @图片1 的人物走进 @图片2 的场景，镜头运动跟随 @视频1，使用 @声音1 的节奏。`
4. 需要首尾帧时打开「首尾帧设置」，从已连接的 1–2 张图片里指定；无需另找端口。选择「不指定」恢复自由引用。增加视频、声音或图片输入时自动恢复自由引用，保留原连线。
5. 选择模型、秒数和分辨率，再点击生成。图片生成节点支持图片和文本；视频节点支持所有已接入类型。

`@` 列表显示整个画布中兼容的素材，包括尚未完成的上游生图节点；排除节点自身和会导致循环的下游。已有连接排在前面。生成会先执行未完成上游。所有连接的素材都会作为输入传给生成服务，`@` 用于描述各素材的用途。

素材编号随连线保存，复制、保存、重启后保留。删除一个素材后，其他素材不会改成它的编号。提示词仍引用断开的编号时，提交前会报错；重新连接或删除对应引用即可继续。该检查不会发起付费任务。

原生 1080P、H3 / Seedance、逐镜秒数、批量分镜、队列恢复、全屏和导出流程保留。
