## 明确的验收边界

- 口播测试使用 macOS 中文合成语音 + FFmpeg 测试画面，验证技术链路。没有把它当成真实人像重构图、剪辑节奏或主观音质验收。
- Claude Code 在本机已安装，但尚未登录，未声称收到真实 Claude 回复。
- 未提供 xAI API Key，因此 Grok 只完成协议实现与模拟测试；需要用户配置后才能验证账户、额度和真实回复。
- 三种场景为原创参数模板，通用小人不是 KAI 母版。不能据此声称支持任意高级动画。
- 未做 Apple 公证、跨机兼容矩阵、长素材压力测试或正式商业发布。

## 修复与重试记录

已修复完整静音边界、重复片段静音交集、转写依赖对 PyAV 的兼容、简体字幕、原生 Sharp 打包、像素配音预览、字幕预览与导出缩放、任务归档恢复。一次口播测试因运行中页面被切走超时；改为隐藏隔离验收窗口后单独重跑通过，该失败没有计为成功。

## 复现

```bash
npm ci
bash scripts/setup-asr.sh
npm test
npm run package:mac
export CS_PACKAGED_EXECUTABLE="$PWD/out/CS 工作台 Pro-darwin-arm64/CS 工作台 Pro.app/Contents/MacOS/CS 工作台 Pro"
node scripts/verify-personal.cjs
node scripts/verify-studio.cjs
node scripts/verify-talk.cjs
```

按顺序执行。每个 UI 验收使用临时用户数据与工程，窗口隐藏，结束后关闭；Codex 测试会使用已登录账户的一次真实请求。口播测试首次运行自动生成合成测试素材，需要 macOS Tingting 声音、FFmpeg 和本地转写环境。
